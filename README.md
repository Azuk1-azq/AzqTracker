# AzqTracker
## AzqTrackerとは？/What is AzqTracker?
AzqTrackerとは、軽量なDiscordにRobloxのプレイ状況を表示するツールです。
Pythonで作られており、コードが公開されています。バックグラウンド起動時のメモリ使用率は約20MBです。
AzqTracker is a lightweight tool that displays your Roblox gameplay status on Discord.
It is written in Python, and its source code is publicly available.Memory usage when running in the background is approximately 20 MB.
